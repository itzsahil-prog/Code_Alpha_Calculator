# Code_Alpha_Calculator
Code Alpha Calculator is a lightweight and responsive web-based calculator built entirely using HTML. This project is perfect for anyone looking for a simple and elegant calculator for basic arithmetic operations.

Features
Basic Arithmetic: Perform addition, subtraction, multiplication, and division.
Responsive Design: Works seamlessly on desktop, tablet, and mobile devices.
Lightweight: Built entirely in HTML for quick loading and operation.
User-Friendly Interface: Simple and intuitive design for ease of use.
Language Composition
This repository is written entirely in HTML (100%).

Getting Started
Prerequisites
To use this project, you need:

A modern web browser (e.g., Chrome, Firefox).
Installation
Clone this repository:

bash
git clone https://github.com/itzsahil-prog/Code_Alpha_Calculator.git
Navigate to the project directory:

bash
cd Code_Alpha_Calculator
Open the main HTML file in your browser:

bash
open index.html
Usage
Open the calculator in your browser.
Use the buttons to input numbers and operations.
View the result on the display.
